### Focus и совместимость

Новый профиль мероприятия программы требует ровно один useContext с code = focus. Прежний UZ Core ActivityDefinition сохраняется без нового обязательного ограничения. В kind дополнительно разрешены ServiceRequest и Task с переводами. Стандартное workflow-shallComplyWith может ссылаться на Questionnaire; примеры скрининга находятся в Integrations. Мероприятие описывает ожидаемую работу, а не её выполнение. Идентификатор программы prg дополняет стабильные идентификаторы определений.
